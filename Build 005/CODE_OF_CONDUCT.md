# Code of Conduct

## Unsere Regeln

Wir möchten eine freundliche und respektvolle Community schaffen.

Bitte:

- Respektvoll miteinander umgehen.
- Konstruktive Kritik geben.
- Keine Beleidigungen oder Diskriminierung.
- Neue Ideen unterstützen.

## Ziel

Das Berufe-Quiz soll ein offenes Projekt sein, an dem jeder gerne mitarbeitet.

Vielen Dank für eure Unterstützung!
