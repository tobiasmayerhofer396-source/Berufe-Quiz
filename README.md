# 🎯 Berufe-Quiz

Ein modernes Quizsystem für Schulen, Berufsinformationsveranstaltungen und Smartboards.

Das Projekt wird mit **HTML, CSS und JavaScript** entwickelt und soll Lehrkräfte sowie Moderatorinnen und Moderatoren dabei unterstützen, interaktive Berufs-Quiz einfach und professionell durchzuführen.
