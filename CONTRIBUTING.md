# 🤝 Mitwirken am Berufe-Quiz

Vielen Dank für dein Interesse am Projekt!

## Entwicklungsablauf

1. Erstelle einen neuen Branch von `Development`.
2. Entwickle deine Änderungen.
3. Teste alle Funktionen.
4. Erstelle einen Pull Request.
5. Nach der Überprüfung werden die Änderungen übernommen.

## Coding Style

- Sauberer und lesbarer Code
- Kommentare bei wichtigen Funktionen
- Einheitliche Einrückung
- Aussagekräftige Variablennamen

## Commit-Nachrichten

Bitte verwende kurze und verständliche Commit-Nachrichten.

Beispiele:

```
Quiz verbessert
Neues Statistikmodul
Fehler im Timer behoben
Moderatorbereich erweitert
```

## Bugs melden

Bitte erstelle ein GitHub Issue und beschreibe:

- Was passiert?
- Wie kann der Fehler reproduziert werden?
- Browser
- Betriebssystem
- Screenshot (wenn möglich)

## Feature-Wünsche

Neue Ideen sind jederzeit willkommen.

Bitte zuerst ein Issue erstellen und die Idee beschreiben.
